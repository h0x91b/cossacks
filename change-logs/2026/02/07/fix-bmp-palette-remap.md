Auto-remap BMP palette indices to the game palette on load in ReadBMP8TOBPX(). Reads agew_1.pal directly (independent of GPal[] which may be zeroed by SetDarkPalette). Only remaps when the BMP palette clearly differs from the game palette (totalDist > 256), so original game BMPs are never touched. Fixes broken colors when 8-bit BMPs are resaved by external editors (mspaint, GIMP, etc.).
