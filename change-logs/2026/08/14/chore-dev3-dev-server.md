Add a dev-3.0 dev server for the project. `.dev3/config.json` wires devScript to `.dev3/dev-run.py`, which kills any running dmcr.exe, builds the solution from the current worktree, copies dmcr.exe/IChat.dll/IntExplorer.dll into the game directory (resolved from $DEV3_PROJECT_PATH, since the game data lives only in the main checkout) and launches the game in the foreground so stopping the dev server terminates it.
